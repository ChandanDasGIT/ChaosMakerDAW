This is the architecture of ChaosMaker

The three layers: frontend/ (QML) talks to wrapper/ (Qt C++), and wrapper/ talks to backend/ (plain C++).
Left out: build*/ (generated) and .claude/ (private notes, ignored by git).

ChaosMaker/
├── backend/                                // pure C++20 engine, no Qt: built as static library, dawengine
│   ├── audiodevice/                        // sound card abstraction and device configuration
│   │   ├── audiodevice.h                   // AudioDevice and AudioCallback
│   │   ├── jackaudiodevice.h/.cpp          // JACK backend client and port negotiation
│   │   └── devicesettings.h/.cpp           // pure C++ device enumeration, valid buffer sizes, port routing
│   ├── core/                               // basic types and string formatting
│   │   ├── audiodata.h                     // decoded immutable audio buffer
│   │   ├── audioview.h                     // non-owning channel/frame audio view
│   │   ├── valueformat.h/.cpp              // pure C++ numeric, unit and playback-position formatting
│   │   ├── version.h/.cpp                  // engine version constant
│   ├── dsp/                                // shared signal processing, scaling, and metering
│   │   ├── levelscale.h/.cpp               // finite gain/dB conversions, normalization, and peak decay
│   │   ├── levelmeter.h/.cpp               // pure C++ meter state, peak decay and threshold classifications
│   │   ├── stereolevelmeter.h/.cpp         // pure C++ stereo meter state and reset logic
│   │   ├── peakmeter.h                     // realtime atomic peak capture
│   │   └── trackmeters.h                   // per-track meter state
│   ├── engine/                             // realtime audio callback and transport
│   │   ├── audioengine.h/.cpp              // AudioEngine: top-level realtime processor
│   │   ├── enginecommands.h                // EngineCommand and EngineEvent
│   │   ├── enginesnapshot.h                // flat read-only arrangement snapshot
│   │   ├── playbackcontrols.h/.cpp         // pure C++ transport state machine, loop ranges, position conversions
│   │   └── snapshotbuilder.h/.cpp          // off-thread EngineSnapshot compilation and routing
│   ├── instruments/                        // instrument catalog and definitions
│   │   ├── instrumentcatalog.h/.cpp        // registered instrument IDs, names, and capabilities
│   │   └── guitar/                         // guitar domain backend
│   │       ├── guitardefinition.h/.cpp     // guitar type names and live input/effect capabilities
│   │       ├── guitarsuiteeditor.h/.cpp    // pedal chain manager, slots, bypass, and reordering
│   │       ├── audiofile/impulsewav.h/.cpp // cabinet IR WAV decoding and resampling
│   │       ├── dsp/                        // pedal controls, delay lines, oversamplers, FFT, pitch
│   │       ├── plugins/                    // GuitarSuite container and pedal processors
│   │       │   ├── guitarsuite/pedalregistry.h/.cpp // pure C++ pedal factory catalog
│   │       │   └── tuner/tunerstate.h/.cpp // off-thread tuner state, freshness, and guidance
│   │       └── presets/guitarsuitepreset.h/.cpp // pure C++ preset schema, JSON IO, and validation
│   ├── mixer/                              // mixer backend
│   │   └── mixerpanel.h/.cpp               // pure C++ track mixer calculations, volume, pan, and mute/solo
│   ├── persistence/                        // document serialization
│   │   └── projectdocument.h/.cpp          // pure C++ session JSON serialization, schema validation, atomic file IO
│   ├── plugins/                            // track-level plugin systems
│   │   ├── eq/
│   │   │   ├── eqpresets.h                 // factory EQ gain curves
│   │   │   ├── eqpresetstore.h/.cpp        // pure C++ preset IO, JSON parsing, validation
│   │   │   └── tenbandeq.h/.cpp            // 10-band EQ filters, descriptors, and gain metadata
│   │   └── trackeffectspanel.h/.cpp        // track effect eligibility, chain models, and slot management
│   ├── processor/                          // plugin base interfaces
│   │   ├── parameter.h                     // thread-safe atomic parameter
│   │   ├── processor.h                     // Processor and ProcessContext
│   │   ├── smoother.h                      // linear parameter ramp smoothing
│   │   └── trackinput.h                    // live track input trim and live EQ stage
│   ├── recording/                          // capture orchestration
│   │   ├── recordingcontroller.h/.cpp      // take lifecycle, recording groups, dry/printed routing, take finalization
│   │   ├── recordinggroup.h                // routing handoff to realtime engine
│   │   └── takerecorder.h/.cpp             // background capture thread, circular buffers, WAV writer
│   ├── rt/                                 // lock-free realtime primitives
│   │   ├── rtaudioring.h                   // bounded realtime audio FIFO
│   │   ├── rtqueue.h                       // single-producer / single-consumer ring buffer
│   │   ├── rtsafe.h                        // RT_SAFE annotation and denormal flush guard
│   │   └── snapshotslot.h                  // atomic snapshot publish and retirement
│   ├── session/                            // document & session state
│   │   ├── project.h/.cpp                  // Project, Track, AudioClip, and atomic undo history
│   │   ├── projectsession.h/.cpp           // session ownership, dirty tracking, autosave policy, restore candidate
│   │   ├── projectactions.h/.cpp           // action/dialog state machine (New, Open, Save, Save As, Close)
│   │   └── tracklist.h/.cpp                // track collection, live monitoring routing, media management
│   ├── settings/                           // application & quick settings
│   │   ├── appsettings.h/.cpp              // startup preferences, autosave intervals, pure C++ INI storage
│   │   └── quicksettings.h/.cpp            // buffer size choices, snap grid modes, formatted status strings
│   ├── tempo/
│   │   └── tempoeditor.h/.cpp              // tempo editing rules, boundaries, and typing validation
│   ├── timeline/                           // arrangement calculations
│   │   ├── timeline.h/.cpp                 // clip placement, snapping, multi-selection, trimming, move history
│   │   └── clipwaveform.h/.cpp             // clip-to-source sample window validation and waveform peak caching
│   └── transport/
│       └── tempomap.h                      // beat-to-sample and sample-to-beat conversions
├── wrapper/                                // Qt 6 C++: thin bridges connecting backend to QML (no domain logic)
│   ├── audiodevice/devicesettingswrap/     // DeviceSettingsWrapper (device list, buffer sizes, routing)
│   ├── dsp/
│   │   ├── levelmeterwrap/                 // LevelMeterWrapper (meter snapshot polling and reset delivery)
│   │   └── stereolevelmeterwrap/           // StereoLevelMeterWrapper (stereo channel meter adapter)
│   ├── engine/
│   │   ├── audioenginewrap/                // AudioEngineWrapper (mirrors AudioEngine, engine lifecycle)
│   │   └── playbackcontrolswrap/           // PlaybackControlsWrapper (transport actions, position updates)
│   ├── instruments/guitar/guitarsuiteeditorwrap/ // GuitarSuiteEditorWrapper (pedalboard model, preset adapter)
│   ├── mixer/mixerpanelwrap/               // MixerPanelWrapper (volume/pan/fader property adaptation)
│   ├── plugins/
│   │   ├── eq/tenbandeqwrap/               // TenBandEqWrapper (10-band EQ property adaptation)
│   │   └── trackeffectspanelwrap/          // TrackEffectsPanelWrapper (track FX slot adaptation)
│   ├── recording/recordingcontrollerwrap/  // RecordingControllerWrapper (take notifications and state bridge)
│   ├── session/
│   │   ├── projectactionswrap/             // ProjectActionsWrapper (native dialog state machine bridge)
│   │   ├── projectsessionwrap/             // ProjectSessionWrapper (document dirty/path signals)
│   │   └── tracklistwrap/                  // TrackListWrapper (QAbstractListModel adapter for tracks)
│   ├── settings/
│   │   ├── appsettingswrap/                // AppSettingsWrapper (QSettings platform bridge)
│   │   └── quicksettingswrap/              // QuickSettingsWrapper (time signature, snap grid bridge)
│   ├── tempo/tempoeditorwrap/              // TempoEditorWrapper (tempo input adapter)
│   └── timeline/timelinewrap/              // TimelineWrapper (selection, snap, and viewport adapter)
├── frontend/                               // QML only: presentation, visual controls, styling, user interactions
│   ├── audiodevice/DeviceSettings.qml      // buffer size and audio device selection UI
│   ├── dsp/
│   │   ├── LevelMeter.qml                  // single-channel level meter display
│   │   └── StereoLevelMeter.qml            // stereo dual-channel level meter
│   ├── engine/PlaybackControls.qml         // transport buttons (play, stop, record, repeat) and time display
│   ├── instruments/guitar/
│   │   ├── GuitarSuiteEditor.qml           // pedalboard editor, pedal slots, controls, presets
│   │   └── GuitarSuitePanel.qml            // pedalboard container panel
│   ├── mixer/MixerPanel.qml                // track channel strips, volume faders, pan sliders, meters
│   ├── pianoroll/
│   │   ├── PianoKeys.qml                   // vertical interactive piano keyboard (MIDI notes 0-127)
│   │   ├── PianoRollView.qml               // piano roll editor: toolbar, ruler, note grid, demonstrative notes
│   │   └── VelocityLane.qml                // collapsible bottom note velocity lane
│   ├── plugins/
│   │   ├── eq/Tenbandeq.qml                // 10-band graphic equalizer sliders and preset manager
│   │   └── TrackEffectsPanel.qml           // track FX slot list and selector
│   ├── session/
│   │   ├── ProjectActions.qml              // New/Open/Save/Save As actions and confirmation dialogs
│   │   └── TrackList.qml                   // track header cards, arm/mute/solo buttons, color picker
│   ├── settings/
│   │   ├── AppSettings.qml                 // application preferences menu
│   │   └── QuickSettings.qml               // quick transport settings popup (meter, snap, count-in)
│   ├── tempo/TempoEditor.qml               // interactive tempo editor with input validation
│   ├── timeline/Timeline.qml               // arrangement lanes, audio clips, waveform display, playhead
│   ├── transportbar/TransportBar.qml       // bottom transport bar composing PlaybackControls & QuickSettings
│   ├── window/
│   │   ├── StatusStrip.qml                 // bottom status notification bar
│   │   └── TopBar.qml                      // top bar composing ProjectActions, AppSettings, DeviceSettings
│   ├── Icons.qml                           // vector icon repository singleton
│   └── Theme.qml                           // visual design system singleton (colors, paddings, fonts)
└── tests/                                  // unit and integration tests
    ├── audiodevice/                        // devicesettings tests
    ├── core/                               // valueformat tests
    ├── dsp/                                // levelscale and levelmeter tests
    ├── engine/                             // playbackcontrols, snapshotbuilder tests
    ├── instruments/                        // catalog, tuner, and guitar pedal tests
    ├── mixer/                              // mixerpanel tests
    ├── persistence/                        // projectdocument serialization tests
    ├── plugins/                            // tenbandeq, eqpresetstore, trackeffectspanel tests
    ├── recording/                          // recordingcontroller tests
    ├── session/                            // project, tracklist, projectsession, projectactions tests
    ├── settings/                           // quicksettings and appsettings tests
    ├── tempo/                              // tempoeditor tests
    ├── timeline/                           // timeline and clipwaveform tests
    ├── ui/                                 // end-to-end UI interaction tests
    └── wrapper/                            // focused Qt wrapper integration tests
