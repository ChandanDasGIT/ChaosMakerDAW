[x] G6  Volume envelope per track, like Reaper's. DONE 2026-11-10 (steps 1-5, uncommitted).
        The user's choices: its own lane under the track by default, switchable to "over the
        clips" from the right-click menu; the envelope MULTIPLIES the fader (0 dB on the line =
        no change; the fader stays an overall level).
        Behaviour:
        - V shows / hides the selected track's Volume lane (under the track, in the timeline and
          the track list). Flat line at 0 dB, shaded area, a "Volume" label and one bypass
          toggle (Reaper's circle and power icon do the same thing; one toggle).
        - Double-click the line: a point at the mouse. Drag a point in time and level (not past
          its neighbours; dB readout while dragging). Right-click a point: delete.
        - Right-click menu: Show over clips / Show in own lane, Delete point, Bypass.
        - Range -inf .. +6 dB on a fader-shaped scale; the engine follows the same scale between
          points, so the line drawn is what is heard. No points or bypassed: no effect.
        - Stopped: the level at the playhead also applies to live sound.
        - Points in samples like clips (stay with the audio when the BPM changes); rescaled when
          a project reopens at another sample rate (like D5).
        - Undoable: add / move / delete points, bypass. Not undoable (view): show / hide, lane
          vs over clips. Saved in the project; older projects open without one.

[x] G7  Mixing plugins for any track, mostly for vocals (the user, 2026-11-10). DONE 2026-11-10

          range, default, unit, card); Settings {bypassed, values}; defaults / sanitize.
          mixeffect: the base processor (parameters from the spec + "bypass", a 20 ms bypass
          crossfade, a fully bypassed effect does no work and restarts clean, reductionDb for
          meters). mixfxfactory: create(type).
        - Compressor (plugins/compressor/mixcompressor, class MixCompressor: the guitar pedal is
          Compressor): Clean (peak), Smooth (RMS, release up to 3x slower while held), Punchy
          (feedback; slope ratio - 1 so the ratio means the same, step capped so the loop
          settles); soft knee (plugins/dynamics/gaincomputer), detector low cut, auto makeup =
          half of a full-scale signal's reduction, linear Mix (parallel compression).
        - De-esser (plugins/deesser): a 12 dB/oct high-pass at Frequency detects; Split mode is a
          dynamic 24 dB/oct high shelf centred on Frequency (a "band + (g - 1)" split was tried:

          Listen plays the detected band; Range caps the cut.

          and width on the wet only. Chaos Verb: 7 modes x 3 colours (1970s dark and steady,
          1980s bright and moving, Now full range), modulated line lengths, a diffuser per
          line, 3-band decay (Bass / Treble decay multipliers), Early / late balance.

-- New tools (the user, 2026-11-10; none planned yet)
[ ] G18 Live pitch monitor FX (for vocals): a scrolling graph of the sung pitch against the
        notes / the key while singing or playing back, with cents off. Can reuse the guitar
        tuner's pitch detection (backend/instruments/guitar/plugins/tuner).
[ ] G19 Guitar tone analyzer: analyse a reference guitar recording and suggest GuitarSuite
        settings that sound close (tone balance, gain / distortion amount, cab character), or
        match automatically by searching amp / cab / EQ settings against the reference
        (offline, like fxrender --analyze). Works best on an isolated guitar stem; a full mix
        needs the guitar separated first, which is out of reach without ML (from-scratch rule).
[ ] G20 Drum pattern analyzer: find kick / snare / hi-hat hits and the tempo in a drum
        recording or loop (onset detection + spectral bands), quantise them, and make a drum
        groove (G1) or a pattern clip from them. The user wants it to work on whole SONGS too
        (a drum stem is the fallback if that is too much). Plan: stage 1 drum stems / loops
        (reliable); stage 2 songs: first pull the drums forward with harmonic / percussive
        separation (median filtering of the spectrogram, hand-written, no ML), then the same
        detection. On songs, tempo and beat grid should be reliable and hi-hat / snare fair;
        the kick under a bass is the hardest. The result is a draft to fix in the piano roll.
[ ] G21 Chord and BPM analyzer (the user, 2026-11-10): from a song, find the BPM / beat grid,
        the key and the chords. Hand-written: tempo from the onset envelope (shared with G20);
        chords from a chromagram (12 pitch classes per beat, the harmonic part from G20's
        separation), matched against chord templates (major, minor, then 7ths ...) and smoothed
        over time (Viterbi); key from the chord / pitch-class profile. Output: the chords on the
        timeline and / or into a Chords track's strips (G3 / G4), BPM into the project.
        Good on clear pop / rock / folk chords; weaker on jazz chords, inversions, heavy
        distortion. G20 and G21 share one analysis foundation (FFT, onsets, tempo, separation).
